# Ridha portfolio

TypeScript, CSS Modules, GSAP (ScrollTrigger, SplitText), Lenis.

- Check with `npm run typecheck`, `npm run lint` and `npm run build`.
- Browser code goes only inside effects, because routes are prerendered.
