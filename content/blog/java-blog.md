Deze week heb ik tijdens mijn stage verder gewerkt met **Java**. Omdat ik tijdens mijn opleiding al ervaring heb opgedaan met objectgeoriënteerd programmeren, waren sommige concepten herkenbaar. Toch merkte ik dat Java in een echte applicatie anders aanvoelt dan tijdens oefeningen op school.

## Werken met bestaande Java-code

Een groot deel van het werk bestaat niet alleen uit nieuwe code schrijven. Ik moest eerst bestaande code lezen en begrijpen voordat ik wijzigingen kon maken.

Ik lette daarbij op de structuur van de applicatie, de verschillende classes en methodes en hoe gegevens tussen verschillende onderdelen worden doorgegeven.

Dat was een goede oefening, omdat je in een echte werkomgeving vaak verder werkt op bestaande projecten.

## API's en data verwerken

Ik heb ook gekeken naar hoe Java gebruikt wordt om met API's te werken. Hierbij worden HTTP-requests gebruikt om gegevens op te vragen of door te sturen.

Bij het verwerken van de response is het belangrijk dat de structuur van de data duidelijk is. Vaak gaat het hierbij om **JSON**, waardoor je de ontvangen gegevens op de juiste manier moet verwerken in je Java-code.

Een eenvoudig voorbeeld is:

```java
String name = "Ridha";

System.out.println("Hallo " + name);
```

Hoewel dit voorbeeld eenvoudig is, gaat het in een echte applicatie vooral om hoe verschillende classes, services en API's met elkaar samenwerken.

## Wat ik heb geleerd

Deze week heb ik vooral geleerd dat programmeren in een bedrijf meer is dan alleen code schrijven. Het begrijpen van bestaande code, logisch zoeken naar een oplossing en testen of een wijziging correct werkt zijn minstens even belangrijk.

Ik wil de komende weken mijn kennis van Java verder uitbreiden en vooral meer ervaring opdoen met REST API's, data verwerking en het werken in een groter project.

Deze ervaring helpt mij om de kennis die ik tijdens mijn opleiding heb geleerd toe te passen in een echte werkomgeving.
